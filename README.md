# Sales & Revenue Analysis Dashboard – Task 1 (Power BI)

## 📊 Project Overview
This dashboard analyzes sales and revenue data using Power BI.  
It visualizes key performance indicators (KPIs) such as Total Sales, Gross Sales, Profit, Units Sold, and Profit Margin.

## 🧩 Key Features
- Interactive slicers for Year and Product
- Monthly trend analysis for Total Sales and Gross Sales
- Product-wise sales comparison
- KPI cards for quick insights

## 🧠 Insights
- Paseo leads with the highest sales (~40M)
- Profit margin steady at 14.23%
- Sales peak during October–December
- Year 2014 shows stronger growth than 2013

## 🛠️ Tools Used
- Power BI Desktop
- Microsoft Excel (Dataset)
